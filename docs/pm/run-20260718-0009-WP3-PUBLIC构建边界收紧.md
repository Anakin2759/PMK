# WP3 PUBLIC 构建边界收紧

- 日期：2026-07-18
- 状态：completed
- 目标：让源码内嵌消费者只看到稳定公共 include，并清零第三方 PUBLIC link 债

## 实施

- `ui` PUBLIC include 仅保留 `BUILD_INTERFACE:include` 与 `INSTALL_INTERFACE:include`。
- 源码根、`src/`、stb 只作为 PRIVATE 构建依赖。
- EnTT、Eigen、spdlog 从 PUBLIC link 收紧为 PRIVATE。
- Event DTO 和 callback 权威定义迁入 `include/ui/api/Event.hpp`。
- Scale 公开头改为纯声明，新增 `src/api/Scale.cpp` 承载 AppConfig 实现。
- Shortcut 类型、函数与 Chain DSL 迁入 `include/ui/api/Shortcut.hpp`。
- ThemePalette/ThemeContext 迁入稳定 Theme 头；新增自有 public `ui::Vec4`，移除内部 Eigen Vec4 alias。
- 内部兼容头仅转发稳定权威头；测试显式声明自身白盒源码/第三方依赖，不再借用 ui PUBLIC 泄漏。
- 架构债基线中的 2 个 PUBLIC include 和 3 个 PUBLIC link 条目全部移除。
