## 所有权契约覆盖

- 静态固定 Slider callback、DropDown vector 和 DragMove callback 的按值公开签名，防止回退到引用、`std::function` 或内部类型。
- 新增 move-only callback 行为测试：lambda 捕获 `unique_ptr`，经 `OnDragStart`、EntityAction、Chain、公开 API 和 bridge 转移到 Draggable 组件，并从组件成功调用。
- 保留 callback-bearing Chain 和 vector-bearing Chain 的单次消费语义，不引入复制或共享所有权。

## 兼容性

全部 Controls setter、默认参数、EntityAction、Chain DSL、callback 和 vector/string move 路径均保持不变。本批不修改 Helper bridge、组件、Runtime 或控件运行时行为。

## 残余风险

callback-bearing Chain 仍是单次消费，应用到无效实体也会消费 callback；这是既有契约，本批未改变。`Entity.hpp` 仍转发源码树类型，install/export consumer 尚未闭环。剩余 Factory/Utils 直接涉及 Runtime、Application 和定时任务边界，不能机械平移。
