# WP3 Text 公共头迁移

- 日期：2026-07-18
- 状态：completed
- 范围：利用已公共化的 `Color`、`Callback` 和 `Policies` 迁移 Text API 头

## 实施

- 新增稳定公共头 `include/ui/api/Text.hpp`。
- 删除旧权威路径 `src/api/Text.hpp`。
- 公共头直接包含 `ui/Callback.hpp`、`ui/Color.hpp`、`ui/Policies.hpp`、Entity 和 Chains；不再包含 `common/Types.hpp`。
- 显式包含 `<string>` 与 `<utility>`，避免依赖 Chains 或 PCH 的间接标准库包含。
- `Text.cpp`、umbrella header、CMake 公共头清单和 PublicLeafHeaders 测试切换到稳定路径。
- 架构门禁将 `Text.hpp` 加入已迁移 API 头集合，禁止旧路径回归。

## 兼容性

全部函数、回调具体类型、DSL 名称、move-only 语义和运行时行为不变。没有修改 `Color`、`Vec2`、`Rect` 或 Eigen ABI，也没有调整 CMake PUBLIC include/link。

## 残余风险

Table 是剩余 Color-only 候选，但模板和容器接口更大；Controls 仍被 `Callback<Vec2>` 阻塞，Animation/Canvas/Utils/Factory/Image 仍需 Vec2/Rect 公共 ABI 决策。当前公开头测试仍运行在源码树 include 环境，不能替代独立 install/export consumer。
